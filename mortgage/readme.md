# 住宅ローン返済額 ＆ NISA資産運用シミュレーター 取扱説明書

本ツールは、住宅ローンの返済期間を長期（最長50年）に延ばすことで毎月の返済負担を抑え、その「浮いた差額」をNISA等の資産運用に回した場合のキャッシュフローや資産形成のシナリオを可視化するWebシミュレーターです。<br>
※対応するお客様の年齢が"44歳以上（ローン期間35年以下）"の方には説明不要ですので、ご注意ください。

## 1. 画面構成と基本操作

画面は大きく分けて**「①条件設定エリア（左側）」**と**「②シミュレーション結果エリア（右側）」**で構成されています。

### ① 条件設定エリア（左側）
スライダーまたは数値入力ボックスから条件を変更すると、右側のシミュレーション結果が即座に自動計算・更新されます。

* **物件販売価格（1,000万円 〜 25,000万円）**
  * 購入する物件の総額を入力します。
* **自己資金 / 頭金（0万円 〜 10,000万円）**
  * 最初に出す頭金の額を入力します。※物件価格を超える値は設定できません。
* **住宅ローン借入金利（0.0% 〜 5.0%）**
  * 想定されるローンの年利（変動金利・固定金利等）を入力します。
* **長期ローンの返済期間設定（35年 〜 50年）**
  * 比較対象とする長期ローンの返済年数を設定します。クイックボタン（`35年` `40年` `45年` `50年`）でワンタップ切り替えも可能です。
* **完済の目標年数（5年 〜 50年）**
  * 何年後に実質完済（一括返済）を目指すかの目標年数を設定します。
* **NISA等 想定運用利回り（0.0% 〜 15.0%）**
  * 差額を投資に回した場合の想定年利（世界株やS&P500インデックスの長期運用平均など）を設定します。
* **「初期値に戻す」ボタン**
  * 設定項目をすべてデフォルト状態（物件8,780万円、借入40年、金利1.125%、運用7.0%等）に戻します。

## 2. 結果の見方と活用ポイント

### メトリックスカード（画面右上）
1. **毎月の返済削減額**
   * 基準となる「35年返済」と比較して、設定した長期ローンで毎月いくら浮くかを表示します。
2. **指定運用年（目標年）の差額積立資産**
   * 毎月の削減額をNISA等で積立運用した場合の「目標年数時点での資産総額」および「運用益」を表示します。
3. **実質一括完済判定**
   * 目標年数時点での「ローン残債」と「運用資産」を比較し、運用資産でローンを一括完済できるかを自動判定します。
   * 最短で何年何ヶ月目に資産が残債を上回る（実質完済できる）かも表示されます。

### シミュレーショングラフ
* **青線（または塗りつぶし）**: 設定した長期ローンの残債推移
* **緑線（または塗りつぶし）**: 毎月の差額を運用した場合の資産推移
* **灰色の破線**: 35年ローンで返済した場合の残債推移（参考）

> **【見方のコツ】**
> 緑色の線（積立資産）が青色の線（ローン残債）を上回った（クロスした）ポイントが、**手持ちの運用資産を使って住宅ローンを実質ゼロ（一括完済）にできるタイミング**となります。

### 返済期間別 詳細比較表
35年、40年、45年、50年（および選択中の年数）における毎月返済額、35年比での節約額、総返済額、目標年数時点での資産と残債の一覧表です。

## 3. 印刷・提案書PDFの出力

画面右上の**「印刷 / 提案書PDF保存」**ボタンをクリックすると、印刷プレビューが開きます。
* 印刷時には背景が自動的に見やすい白地モードに切り替わり、ボタンや入力UIなどの非印刷要素が隠されます。
* 送り先を「PDFに保存」に選択することで、そのままお客様へのお渡し用資料や提案書として保存可能です。
