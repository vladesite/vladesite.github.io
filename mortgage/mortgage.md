## 第1部：取扱説明書（ユーザー向け操作ガイド）

本システムは、住宅ローンの返済期間を長めに設定することで毎月の返済額を抑え、その「浮いた差額」をNISA等で運用して早期完済を目指すシミュレーションを行うツールです。

### 2. かんたん3ステップ使い方手順

#### **ステップ1：条件を入力する**
画面左側の入力エリアで、お客様の条件に合わせて数値を変更します。
* **つまみ（スライダー）を左右に動かす**か、**数字の入力ボックスに直接数字を入力**してください。
* 返済期間は「35年」「40年」「45年」「50年」のボタンを押すだけで一括切り替えができます。

```
  【数字を直接入力する】
   [ 8780 ] 万円  <-- ここをクリックして半角数字を入力できます
   
  【つまみで直感的に変える】
   [=====o=============]  <-- 丸を左右にドラッグして動かします
```

#### **ステップ2：シミュレーション結果を確認する**
数値を変えると、画面右側の結果が自動的に再計算されます。

1. **毎月の返済削減額**: 35年ローンで組んだ場合と比べて、毎月いくら安くなるかが表示されます。
2. **○年目の差額積立資産**: 浮いた差額をNISAで運用した場合の将来の資産額が表示されます。
3. **実質一括完済判定**: 設定した目標年数において「運用資産がローン残債を上回り、一括完済できるか」を判定します。

#### **ステップ3：提案書として印刷・PDF保存する**
画面右上の**「印刷 / 提案書PDF保存」**ボタンを押すと、背景が印刷用の見やすい白地に自動変換され、紙への印刷やPDF化がスムーズに行えます。

```
  [ 画面右上 ] ----------------------------+
  |  [i] 印刷 / 提案書PDF保存  <-- クリック|
  +----------------------------------------+
```

## 第2部：システム設計書（エンジニア・保守担当者向け）

### 1. システム概要
* **システム名称**: 住宅ローン長期返済 ＆ NISA資産運用シミュレーター
* **形態**: 単一ファイル型（Single File Component）Webアプリケーション（HTML5 / JavaScript / CSS3）
* **目的**: 35年を超える長期住宅ローン（最長50年）の月々返済額軽減効果と、軽減分のNISA積立運用による複利効果を可視化し、早期完済プランを提示する。

### 4. 主要計算アルゴリズム仕様

#### (1) 住宅ローン毎月返済額（元利均等返済） $PMT$
$$PMT = P \times \frac{r(1+r)^n}{(1+r)^n - 1}$$
* $P$: 借入総額（円）
* $r$: 月利（年利 $\div 12 \div 100$）
* $n$: 総返済回数（年数 $\times 12$）

#### (2) 指定月数（$m$ヶ月）経過後のローン残債 $Bal(m)$
$$Bal(m) = P \times \frac{(1+r)^n - (1+r)^m}{(1+r)^n - 1}$$

#### (3) 毎月差額積立の将来価値（複利運用） $FV(m)$
$$FV(m) = S \times \frac{(1+i)^m - 1}{i}$$
* $S$: 毎月節約額（35年ローン返済額 − 長期ローン返済額）
* $i$: 想定運用月利（年利 $\div 12 \div 100$）
* $m$: 運用月数

### 5. 特筆機能・メディアクエリ設計

1. **印刷/PDF化最適化 (`@media print`)**:
   * ダークモード画面を自動的に白背景・濃色文字へ反転。
   * 操作系UI（入力スライダーや各種ボタン）の非表示化 (`.no-print`)。
   * 印刷時の Chart.js 描画色（軸・グリッド線）の動的切替処理 (`beforeprint` / `afterprint` イベントハンドラ実装)。
2. **レスポンシブ・コンポーネント化**:
   * モバイル～デスクトップまで1画面で完結するグリッドレイアウト（Tailwind CSS）。
   * 外部依存ファイルをCDNに集約し、環境構築不要でブラウザ起動が可能。
